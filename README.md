README – Elektronický deník

Jazyk a verze:

  Programovací jazyk: Java

  Verze: Java 17

Postup spuštění:
  
  Nainstalujte JDKe.
  
  Otevřete projekt v prostředí IntelliJ IDEA nebo jiném IDE podporujícím Javu.
  
  Spusťte hlavní třídu programu (Main).
  
  Program se spustí v konzoli a zobrazí nabídku dostupných funkcí.

Data deníku se ukládají do souboru denik.dat. Pokud chcete vytvořit nový deník, smažte tento soubor.
